# Resumen de Manuales Creados

Se han generado los manuales de usuario interactivos en formato HTML y sus versiones de impresión en formato PDF dentro de la carpeta `docs` del proyecto. Ambos manuales están diseñados para ser claros y accesibles para usuarios no familiarizados con la tecnología (delegados y administradores).

## 📄 Archivos Generados

### 1. Manual del Portal de Registro (Delegados)
* **Público:** Delegados e inscritos (rango de edad: 16 a +60 años).
* **Formatos disponibles:**
  * 🌐 **Versión Web Interactiva:** [manual_registro.html](file:///Users/raulcanul/Documents/Dev/registro-plenarias/docs/manual_registro.html)
  * 📄 **Versión PDF para Impresión/Envío:** [manual_registro.pdf](file:///Users/raulcanul/Documents/Dev/registro-plenarias/docs/manual_registro.pdf)
* **Características clave:** Paso a paso visual de pre-registro (fases 1, 2, 3), explicaciones sencillas para pagos en línea y efectivo, flujo de acreditación con carta pastoral y descarga de nombramiento.

### 2. Manual del Panel de Administración (Staff/Administradores)
* **Público:** Staff y administradores de la CNBM (rango de edad: +30 años).
* **Formatos disponibles:**
  * 🌐 **Versión Web Interactiva:** [manual_admin.html](file:///Users/raulcanul/Documents/Dev/registro-plenarias/docs/manual_admin.html)
  * 📄 **Versión PDF para Impresión/Envío:** [manual_admin.pdf](file:///Users/raulcanul/Documents/Dev/registro-plenarias/docs/manual_admin.pdf)
* **Características clave:** Gestión de delegados, aprobación física de pagos en sitio y de cartas de acreditación, uso del escáner QR en sede, asignación de excepciones de cupo e instrucciones para la exportación de base de datos a CSV.

---

> [!NOTE]
> Las versiones PDF conservan las simulaciones de las pantallas de las aplicaciones y la maquetación exacta, ideales para imprimir físicamente o compartir por WhatsApp/Correo.

> [!TIP]
> Los archivos HTML interactivos se pueden cargar a un servidor web o abrir directamente en cualquier navegador para ver las simulaciones de pantalla en vivo.
